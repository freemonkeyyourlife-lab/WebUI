# K.I.T.T. local runtime command reference

## Startup
bash WebUI/KITT/installer/start_local.sh

## API endpoints
- http://localhost:8000/health
- http://localhost:8000/agents
- http://localhost:8000/services
- http://localhost:8000/presets
- http://localhost:8000/tasks

## Dashboard
- Open WebUI/KITT/dashboard/index.html in browser
- Or serve with a simple local static host if needed

## Bundle
bash WebUI/KITT/installer/build_local_bundle.sh
