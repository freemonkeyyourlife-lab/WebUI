# K.I.T.T. (Knight Integrated Tooling & Tasking)

This directory is the K.I.T.T. subproject inside the WebUI repository. K.I.T.T. is the central coordinator / interface for the Free Monkeys platform. It contains documentation, system prompts, and orchestration configuration for the agent network.

Goal
- Provide K.I.T.T. as the main coordinator and UI entrypoint for the A‑Team agents.
- Store the master project overview and system prompt used by agents.

Voice
- The project owner indicated they want to use the Knight Rider (K.I.T.T.) voice for the main interface. Voice model selection and legal checks are required before cloning or imitating any copyrighted voice.

Structure
- docs/: master overviews and architecture notes
- prompts/: system and agent prompts
- src/: (placeholder) where the front-end/back-end code will go
