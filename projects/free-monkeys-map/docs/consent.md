# Consent & Voice usage (Project B)

Dieses Dokument wiederholt die zentralen Punkte zur erlaubten privaten Nutzung von Stimmen und beschreibt die minimale Consent‑Anforderung für Free Monkeys® Map (MI).

- Jede hochgeladene Audiodatei muss vom Nutzer mit einer Checkbox bestätigt werden (`consent: true`).
- Generierte Stimmen dürfen nicht öffentlich bereitgestellt werden ohne explizite Genehmigung.
- Alle Uploads werden im Audit‑Log erfasst (wer, wann, preset).

Siehe /WebUI/KITT/docs/Voice_Usage_Policy_de.md für die vollständige Policy.
